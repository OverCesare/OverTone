OverTone 0.1 / Development preview

Get OverTone
on your Mac.

Download the app, move it to Applications and follow its setup. This is an early development preview, not a stable release.

What you need

  • An Apple silicon Mac running macOS 14 or later.
  • Enough memory and storage for the model you choose. Engines and models are separate downloads.

The app download is about 2.7 MB. You do not need Xcode, a package manager or Terminal to install it.

1. Download and copy

Download OverTone for Mac, open the DMG and drag OverTone into Applications. Open the copied app from Applications. You can then eject the disk image.

The SHA-256 checksum is available for an optional integrity check.

2. Allow the first open

This preview is signed locally but is not notarized by Apple. macOS may block it because it cannot verify the developer.

  1. Try opening OverTone from Applications.
  2. Open System Settings → Privacy & Security, scroll to the security section and choose Open Anyway.
  3. Confirm only if you obtained OverTone from this project's website or repository.

See Apple’s official instructions. The exception can be unavailable on a managed Mac, and a new build may require another approval. Do not disable Gatekeeper or remove quarantine attributes. If macOS reports malware or a damaged file, do not assume it is the ordinary developer warning.

3. Set up your workspace

On first launch, OverTone can help you choose a local model, reuse an existing installation, install engines only or connect a compatible server. Internet access starts off; downloads begin only after you enable the relevant access. You can also skip setup and configure the app later.

Downloading the app is separate from downloading an engine or model. Model downloads can be several GB and depend on your connection. Watch the walkthroughs.

Updating or removing the app

Quit OverTone before replacing it in Applications. Replace the whole app rather than merging its contents. Conversations, preferences and managed models are stored separately, by default in ~/Library/Application Support/OverTone. Removing the app alone does not remove this folder.

If your account cannot write to the shared Applications folder, use an administrator-approved installation or your personal Applications folder. Keep a single installed copy.

Build from source

For development, download the source ZIP and open Terminal in the extracted OverTone folder. Its SHA-256 checksum is also available.

Install Apple’s Command Line Tools if needed:

xcode-select --install

The build requires the macOS 15 SDK or later, from Xcode 16 or later. Choose tools supported by your Mac using Apple’s compatibility table.

make -j"$(sysctl -n hw.logicalcpu)"
make run

No package manager is required. make run installs and opens /Applications/OverTone.app. For a per-user installation, use the same location consistently:

make run INSTALL_DIR="$HOME/Applications"

See the repository README for build details, tests and current limitations.
